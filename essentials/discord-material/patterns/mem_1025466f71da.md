Operating philosophy (from mentor Tom, Discord 8/21/26): How to guide a small model like deepseek-flash. 1) Code is ground truth, NOT specs — markdown specs throw away code definitions and burn tokens re-iterating; markdown is only for post-code artifacts when a run lasts 4-10 days. 2) The reusable unit is the SKILL (the shortcut), not the spec — stack shortcuts so a cheap model "makes no mistakes because the workflow is written in code or a skill somewhere." 3) Prewalk is the best tool — give the model context and let it search context, don't hand-plan every step. 4) Small models are agentically the same as frontier models; they just lack knowledge, so feed them ground truth. 5) New stuff costs time+tokens; existing foundations are shortcuts on both — the more you stack, the faster work becomes. This is the core reason for squeezing repos into foundation skills.
