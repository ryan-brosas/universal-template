Turn the useful method from this session into a reusable skill or playbook. First
inspect the actual experience: what worked, why, when it applies, and its limits.
Use knowledge/playbooks/session-improvement-compiler/README.md to establish the
lesson, then knowledge/playbooks/writing-skills/README.md for authoring.

Use this when the lesson comes from session experience that must be understood
first. When the procedure and its owner are already settled, write it directly
after checking `knowledge/playbooks/writing-skills/README.md`.

Preserve the technique, sequence, decision, or reasoning shortcut another agent
would otherwise rediscover, not a transcript summary or generic advice. Improve
an existing owner if it genuinely fits; do not force code fixes or project-only
choices into a skill. If no reusable method qualifies, explain that. Verify that
a representative future task can find and use the result.
