# Compile one session into a durable skill

Compile the learnings of one bounded session into the cheapest durable owner,
preferring a skill only when a procedure qualifies. This is the deliberate
promotion pass over a session, not an automatic end-of-session ritual.

## Framing

Raw session JSONLs are the record. Memory projections (Hindsight) and pattern
projections (Codebase Memory over ast_grep and formatting) can surface candidate
leads cheaply; they are not authority. Deciding what a session actually taught,
and what deserves a durable artifact, remains a deliberate pass over the
evidence.

## Contract

1. Bound the session: the current session by default, or one named historical
   session. Cross-project or global evidence requires an explicit request.
2. Load `knowledge/playbooks/session-improvement-compiler/README.md` and follow it end to
   end; it owns the evidence ledger, classification, owner search, and
   verification. The `compile-skill` prompt owns procedure authoring.
3. Verify every candidate against raw session events and current source.
   Projections and summaries are leads, never independent proof.
4. Improve an existing owner before creating a skill. A new skill needs distinct
   ownership, a recurring need, and a stated lift hypothesis; follow
   `knowledge/playbooks/writing-skills/README.md`.
5. Implement qualified improvements when this command is invoked explicitly,
   then report evidence used, artifacts created or improved, checks run, and
   material deliberately not saved.
