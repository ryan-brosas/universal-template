exceptions, and verification methods rather than a session transcript or facts

discoverable owner only when none fits. Apply routine instruction improvements
within the granted scope; learning from a task does not expand permission to
publish, message others, change runtime setup, or expose private information.
If the lesson is already captured or nothing new merits retention, say so
without creating another artifact.
