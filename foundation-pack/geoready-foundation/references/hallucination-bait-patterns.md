### Decisive source
```python
# gap #4.16.3: this used to match the bare product names (chatgpt|claude|bard|gemini|
# copilot), so any page that merely *wrote about* AI search was flagged as undisclosed
# AI content — which is precisely this tool's own audience. Only the assistant name
# paired with an authoring verb counts as a claim of generated content; a naked mention does not.
_AI_GENERATED_RE = re.compile(
    r"\b(ai[- ]?generated|"
    r"generated by ai|"
    r"(?:written|generated|created|produced|authored|drafted)\s+"
    r"(?:by|with|using)\s+"
    r"(?:ai|an ai|chatgpt|claude|bard|gemini|copilot|an llm|a language model))\b",
    re.IGNORECASE,
)
```

**Flow:** extract analysis text (page text + meta description via `_extract_text_for_analysis`) → run each compiled family: unsourced `%` stats, certainty verbs ("studies show", IT variants), projections ("by 20XX", "si stima che"), wide ranges ("between N and M million"), AI-authorship (above), self-citations ("according to our data" — circular sourcing), missing units ("3x faster" without baseline), medical claims (cure/treat verbs) → severity from total-baits bands.
**Invariant:** Every family requires its CONTEXT words, not just numbers — a page stating "37%" inside a cited sentence still matches the regex here because source-presence is measured by separate detectors (attribution/cite-sources), keeping each module single-purpose. Verb-gating product names is the reusable lesson: presence-of-word ≠ claim-of-authorship.
