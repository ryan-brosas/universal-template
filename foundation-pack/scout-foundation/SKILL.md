## Capsule map
- **Egress & resilience** — `proxy-ladder` + `retry-semantics`: one env-keyed ladder feeds every client through shaped accessors; scrapers speak a typed contract (`None`=skip / `RuntimeError`=fatal) that exactly one loop consumer maps to continue-vs-break. `scrape-loop-export`: budgets differ 6×–12× per platform and only fire between items. `dead-twins-audit`: the library health-check trio is never wired — the live probe is the menu's own httpx reimplementation.
- **Config & lifecycle** — `env-persistence`: settings ARE the `.env`, rewritten in place and mirrored live; `forced-update-gate`: never block startup on a version check, always block running outdated; `interactive-shell`: encoding shim → argv filter → env → lazy imports → catch-all menu loop.
- **Data contract** — `profile-contract` + `contact-extraction`: uniform core fields (`platform` literal, truthiness validity gate), monotonic key growth, cheap-bio vs rich-HTML contact tiers; `scrape-loop-export` carries the CSV schema strategies those shapes force.
- **Email intelligence** — `smtp-verify` + `smtp-accept-all-probe` + `company-pattern-emails` + `candidate-funnel`: MX→RCPT differential verification, headline-to-domain-to-pattern invention, six ordered sources competing through tiered scores into one argmax winner plus a 0–100 lead score. `email-pattern-inference` (observe-before-predict, twin-generator split) and `company-domain-guessing` (DNS-MX existence oracle over a slug+TLD ladder) carry the seams pass 2 folded into those summaries; `bio-link-scavenging` adds the ≤3-link bio scavenge through the fail-open `_fetch_page` primitive, and `phone-extraction-ladder` pins the structured-first phone ordering shared by all extraction paths; pass 4 completes the plane with `contact-page-crawl` (the five-path crawl + two-signal early exit behind every 'website' candidate), `hunter-last-resort` (the gated paid lookup whose position encodes priority), and `lead-score-bands` (the post-discovery 0–100 ranking with its overlapping follower bands); pass 5 opens the normalization plane with `email-domain-normalization-funnel` (the `_extract_domain` step every pattern/generator consumer shares, and its three garbage-out string classes).
- **Per-platform acquisition** — `instagram-html-scrape` (body-sniffed 200s, mobile UA), `linkedin-voyager-session` (cookie session w/ self-healing CSRF cache), `rehydration-extraction` (three JSON-in-HTML idioms), `linkbio-resolution` (multi-host identity + link classification) with `linktree-host-dispatch` carrying the fetch/dispatch/gate layer those probes run through, `tiktok-client-contract` (the one httpx client + its typed-error dialect), `youtube-channel-scrape` (consent + redirect unwrap), `twitch-gql-scrape` (public GQL gates + direct failover).
- **Operator surface** — `prerequisite-gates` (refuse-before-render for credentialed flows, duplicated at every dispatch site) + `settings-live-config` (menu mutations validated at set time and made live by the dual-write helper) + `interactive-entry-contract` (the five-phase flow template all eight platform entries follow; LinkedIn's `/in/` splitter and linktree's inline union-schema export are the only sanctioned deviations).
