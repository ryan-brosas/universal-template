# Spotlight nonce fence — how does untrusted user text get shown to an LLM without becoming instructions?

**Source:** mike AGPL-3.0 `main@3ad9a5ff`; Codebase Memory `ext-mike`. **Question:** How do you fence document bodies, filenames, and profile facts so injected content can neither escape the fence nor forge a plausible one?

## Per-request nonce on BOTH tags + smuggled-token neutralization
**Path/Symbol:** `backend/src/lib/chat/contextBuilders.ts:33` (`generateSpotlightNonce`), `:43` (`neutralizeFenceTokens`), `:63` (`spotlight`). Direct test: `src/lib/__tests__/spotlight.test.ts`.
**Signature:** `generateSpotlightNonce() -> 32-hex-char string` (crypto.randomBytes(16)); `spotlight(text, nonce) -> "<untrusted-content nonce=N>…</untrusted-content nonce=N>"`.
**Data Shape:** ONE nonce per request is generated by the route and threaded through buildMessages AND every tool result, so system-prompt filenames and tool-returned bodies share the same boundary token.

### Decisive source
```ts
return String(text)
    .split(nonce).join("[redacted-nonce]")                       // echoed nonce unusable
    .replace(/<(\/?)(untrusted-content|workflow-instructions)/gi,
             "&lt;$1$2");                                        // smuggled tags inert
```

**Flow:** wrap → the model is told (system prompt) everything inside is DATA. Escape requires forging BOTH opening and closing tags with a nonce the attacker cannot know (fresh 128-bit per request) — and even a correctly-guessed-looking tag inside the data was already HTML-escaped before wrapping.
**Invariant:** Neutralization happens BEFORE interpolation into the template, covering both fence families (an untrusted body cannot close itself AND cannot fabricate an `<workflow-instructions>` opener either). The redaction must be `.split().join()` (all occurrences), not replace-first.
**Probe:** `grep -c 'it(' src/lib/__tests__/spotlight.test.ts` → 12 incl "puts the nonce on BOTH the opening and closing tags", "neutralizes a forged closing tag so untrusted text cannot escape the fence", "redacts an echoed nonce…".
