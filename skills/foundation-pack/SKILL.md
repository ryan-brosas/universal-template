# Foundation pack

Historical source evidence, not instructions to apply wholesale. Current project
requirements, source, tests, and runtime behavior win. Prefer an operational skill
for ordinary implementation; use this pack for a concrete prior-art question.

## Choose one category

Under `../../knowledge/foundations/categories/`:

- [Frontend](../../knowledge/foundations/categories/frontend.md): UI frameworks, components, rendering, editors.
- [Backend](../../knowledge/foundations/categories/backend.md): services, validation, jobs, orchestration.
- [Data](../../knowledge/foundations/categories/data.md): databases, search, RAG, memory.
- [Agent frameworks](../../knowledge/foundations/categories/agent-frameworks.md): orchestration, model clients, agent applications.
- [Agent harnesses](../../knowledge/foundations/categories/agent-harnesses.md): coding agents, Pi, Veda, context and tools.
- [Browser automation](../../knowledge/foundations/categories/browser-automation.md): crawling, computer use, browser control.
- [Developer tools](../../knowledge/foundations/categories/developer-tools.md): protocols, IDEs, testing, builds.
- [Infrastructure](../../knowledge/foundations/categories/infrastructure.md): deployment, observability, security, desktops.
- [Applications](../../knowledge/foundations/categories/applications.md): collaboration, publishing, CRM, media.
- [Marketing](../../knowledge/foundations/categories/marketing.md): SEO, outreach, analytics, acquisition.

Read the matching category, then the selected foundation's `README.md`. Its topic
map points to capsules; read only the relevant one, using its own source revision
and caveats. Open `references/index.md` only when the topic map is insufficient.
For a known source, go directly to its directory. If the category is unclear,
search category files first rather than loading every index. Never load the pack
recursively or add its knowledge directory to host skill discovery.
