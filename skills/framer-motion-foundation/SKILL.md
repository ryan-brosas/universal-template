# framer-motion (Motion): animation engine contracts

## Use this for
Use when building or porting spring-based animation engines and value-driven motion systems: physics-spring closed forms with duration/bounce/visualDuration resolution, MotionValue velocity tracking with staleness rules, follower values that track moving targets frame-rate-invariantly, an eight-step frameloop with layout-safe read/write ordering, a playback machine over generators (repeat/mirror/delay/pause/speed), inertia boundary-catch composition, generator→CSS `linear()` serialization, and dependency-auto-collecting derived values. Source code and direct tests are ground truth; references carry decisive excerpts and graph retrieval.

## Capsule map
- **Spring resolution** — `spring-options-resolution`: `getSpringOptions` admits exactly two disjoint families; any explicit stiffness/damping/mass silently discards duration/bounce; duration-family resolution zeroes inherited velocity (interrupted-animation oscillation fix) and forces mass=1; visualDuration compiles via `root=(2π)/(vd·1.2)`, `k=root²`, `c=2·clamp(0.05,1,1−bounce)·√k`. `spring-closed-form-solver`: one mutable state object per generator; three damping branches with hoisted trig coefficients; overdamped sinh/cosh argument capped at 300; rest requires BOTH speed and delta under thresholds (granular <5-unit animations use 10× tighter defaults); incoming velocity negated into solver space; `velocity(t)` returns px/ms while integration runs in seconds.
- **Value pipeline** — `follow-value-restart-ladder`: source changes store latest and schedule ONE postRender restart (stable-ref Set dedupe); equal-value early-out stops ghosts; running-animation analytical velocity replaces frame-delta estimates on every restart so 240 Hz followers match 60 Hz within 10% (#3265/#3407); string units extracted once and re-applied to every write. `motionvalue-velocity-ledger`: prev-frame values roll only at eventloop-frame boundaries; velocity = 0 when >30 ms stale or window >30 ms; always units/second (×1000 on ms deltas); jump() wipes history and kills the passive effect; set() routes through attached passive effects — the hook that makes useSpring transparent.
- **Scheduling** — `frameloop-eight-steps`: setup→read→resolveKeyframes→preUpdate→update→preRender→render→postRender, unrolled per frame; immediate=true joins the current frame ONLY inside its own step's processing; flushSync-inside-step defers via flushNextFrame; keepAlive WeakSet keeps rAF alive with real deltas afterwards; first wake uses synthetic 1000/60 then clamps [1,40] ms. `sync-time-clock`: time.now() latches once per microtask window, freezing to frameData.timestamp while processing — the reason intra-frame velocity math is coherent.
- **Playback** — `jsanimation-playback-machine`: calculatedDuration cached ON the generator for timeline reuse; totalDuration = (calc+repeatDelay)(repeat+1)−repeatDelay; odd iterations reverse progress (with repeatDelay adjustment) or swap to a prebuilt mirrored generator (negated velocity); delay phase replays keyframes[0] from a reused state object; finished animations snap via getFinalKeyframe (first kf on negative speed or odd non-loop repeats) EXCEPT inertia; non-numeric springs ride a [0,100] percent bridge through mix(). `inertia-boundary-catch`: friction decays toward origin+power·velocity (modifyTarget may remap, amplitude recomputed); out-of-bounds sample latches timeReachedBoundary ONCE and builds a catch spring whose clock starts at the crossing; hasUpdatedFrame prevents double friction evaluation per tick.
- **Derived values** — `derived-value-graph`: opening collectMotionValues.current before evaluating a transformer records every .get() as a dependency; changes schedule ONE immediate preRender update regardless of input count; destroy unsubscribes and cancels pending frames; interpolate normalizes descending inputs by reversing both arrays and clamps by default. `react-value-hooks`: attach in useInsertionEffect so mount paint is correct; combined values sync during render then coalesce via frames; dep-less layout effect resubscribes each commit; options keyed by JSON.stringify; useVelocity polls until decayed to zero; static mode swaps animation for setState.
- **Output bridge** — `generator-css-bridge`: settle time measured at 50 ms steps capped at 20 s (Infinity beyond); easing normalized on synthetic [0,scale] keyframes then divided by scale; serialized as rounded `linear()` points pinned byte-for-byte by tests; applyToOptions mutates a transition in place from spring → pre-baked keyframes tween for WAAPI renderers.
- **Scroll surface** — `use-scroll-surface`: public shape {scrollX, scrollY, scrollXProgress, scrollYProgress}, progress clamped [0,1] from intersection offsets, updates coalesced outside React render; internals deliberately deferred to next pass.
