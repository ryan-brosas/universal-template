# Compaction state projection — resume a compacted session without re-summarizing

**Source:** Cline Apache-2.0 `main@4f836ae7d0ed29ece7ef4a2a478deb470fdd056e`; Codebase Memory `ext-cline`. **Question:** How can a persisted "compacted view" be re-applied to the growing canonical transcript across process restarts, safely?

## Prefix-hash sidecar + append-only tail projection
**Path/Symbol:** `sdk/packages/core/src/session/models/session-compaction.ts:60-190` (`sourceMessageHashInput`, `sourcePrefixHash`, `createSessionCompactionState`, `projectSessionCompactionState`).
**Signature:** `projectSessionCompactionState(state, sourceMessages) → MessageWithMetadata[] | undefined`; state = `{version:1, updated_at, conversation_id?, source_message_count, source_prefix_hash?, source_last_message_key?, messages[], system_prompt?}` (zod-validated).
**Data Shape:** Hash input per message = fixed field order `[role, content, agent, sessionId, metadata, modelInfo, metrics]` over the PERSISTED shape; **`id` and `ts` are deliberately NOT hashed** — they are transport identity regenerated by the codec on every round-trip; hashing them made projection fail for semantically identical prefixes and persistence was silently rejected every turn. User text is normalized through `formatDisplayUserInput` before hashing.

### Decisive source
```ts
// v2: dropped volatile id/ts from the per-message hash input. Sidecars
// written with v1 fail projection once and are replaced by the next
// compaction (the stale-write guard permits replacing unprojectable state).
hash.update("cline-session-compaction-source-v2\n");
...
const canProjectState = hasMatchingSourcePrefix || hasMatchingLegacyBoundary;
if (!canProjectState) { return undefined; }
return [
    ...cloneMessages(state.messages),
    ...cloneMessages(sourceMessages.slice(state.source_message_count)),

```

**Flow:** after each compaction the host saves `{count, prefix-hash-of-source, compacted messages}` → on later turns, project = verify count ≤ live length AND sha256 of first `count` canonical messages matches → return compacted-view + live tail appended. Mismatch ⇒ undefined and the wrapper (`createCompactionStateAwarePrepareTurn`, compaction.ts:643-710) re-compacts from the projection+tail instead of full history; saveState must validate against the EXACT canonical messages the hash was computed over (a separately derived transcript can legally differ mid-turn and spuriously reject).
**Invariant:** Boundary keys prefer `id:` when present, else `ts:<role>:<ts>`, else `content:<role>:<json>` (roles must not contain ':'); legacy boundary matching only fires when no prefix hash exists. Projection output is cloned twice — never aliases into the sidecar or the live array.
**Probe:** `grep -cF 'cline-session-compaction-source-v2' .../session-compaction.ts` → 1; `grep -cF 'hasMatchingLegacyBoundary' ...` → 2; upstream test "re-compacts a projection that starts with a compaction summary".
