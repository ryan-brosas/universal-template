# JetBrains IDE distributions: platform & plugin manifest internals

## Use this for
Use when building plugin/extension registries, capability manifests, language/file-type registration layers, static-analysis rule catalogs, or runtime feature-flag systems modeled on how JetBrains IDEs declare and compose capabilities. The targets are INSTALLED IDE BUILDS (jars + packaged resources), not source: the valuable surface is `META-INF/*.xml` descriptor catalogs inside module jars, per-plugin `META-INF/plugin.xml`, keymaps, and options schemas. Source code and direct tests are ground truth where present (helpers plane); references carry decisive excerpts and graph retrieval.
