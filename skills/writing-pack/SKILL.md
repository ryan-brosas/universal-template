# Writing pack

Read the procedure for the requested writing outcome, not every stylistic guide.
Resolve relative references from the selected procedure's directory.

- Conversion-focused copy, positioning, headlines, CTAs or onboarding text:
  [copywriting](../../knowledge/playbooks/copywriting/README.md).
- Polish prose in the house style:
  [house-writing-style](../../knowledge/playbooks/house-writing-style/README.md).
- Technical documentation and architecture decisions:
  [documentation-and-adrs](../../knowledge/playbooks/documentation-and-adrs/README.md).
- Markdown conventions:
  [markdown-writing-practices](../../knowledge/playbooks/markdown-writing-practices/README.md).

For developer-documentation conventions, code examples, Mailchimp content or
Notion workflows, choose one [writing topic](references/topics.md). Keep facts
and claims grounded in the user's source; do not create extra documents merely
because a procedure exists. Private proposal procedures remain local and are not
copied into this public pack.
