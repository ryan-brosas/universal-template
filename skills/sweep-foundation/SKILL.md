## Capsule map
- **Webhook entry contract** — `webhook-entry-signature-always-200`: constant-time HMAC verify that fails OPEN without a secret; handler exceptions logged and swallowed so GitHub always gets 200.
- **Latest-wins threads** — `latest-wins-ticket-thread-replacement`: `repo-issue` keyed registry; old thread killed via `PyThreadState_SetAsyncExc(SystemExit)` with res==0/res!=1 cleanup ladder.
- **Coalescing priority queue** — `per-pr-comment-coalescing-queue`: lock-held put rebuilds heap keeping only `priority <= new`; named-worker guard via `threading.enumerate()`; blocking `get()` holds the same lock `put()` needs.
- **Event-router gate ladder** — `event-router-gate-ladder`: `match event, action`; label auto-provision tolerates 422 already_exists; `(gates) or restart_sweep` precedence bypass; buttons only count when `changes.body_from` present.
- **GHA autofix attribution** — `gha-autofix-attribution-chain`: sender→commit.author→assignee→refuse chain; base-passing precondition; <2 prior fix comments; free-tier refusal.
- **Progress-comment lifecycle** — `single-progress-comment-lifecycle`: reuse-first bot comment; `.edit` monkey-patched to append BOT_SUFFIX; BadCredentials recovery re-finds/recreates the comment.
- **Branch/commit/PR ladder** — `branch-commit-pr-assembly-ladder`: `/`→`_` swap if bare `sweep` branch exists; 9× `_hash5` suffix retries; 50-char commit message; polluted-path sanitization; draft conversion last.
- **Ticket ledger write path** — `chat-logger-ticket-ledger`: month+date `$inc` upsert counters keyed on username; same-pass `purchased_tickets: -1` when over cap; gpt3 tickets isolated in `{month}_gpt3`; class-level read caches; off-thread writes parked in `global_threads`.
- **Faster-model tier gate** — `faster-model-tier-gate`: use_faster_model ladder (payer ≥500, trial ≥20, free ≥5-monthly/>3-daily, inactive ⇒ always); Mongo-down degrades fail-closed; determine_model raises ValueError inside call_openai when allocation exhausted with purchased==0.
- **Snippet type taxonomy** — `snippet-type-taxonomy-funnel`: first-match prefix/suffix/substring tables → tools/junk/deps/docs/tests/source; four per-type tuning dicts (percentile floor, score floor, result count, rerank budget); junk excluded structurally by __iter__ never yielding it (the "junk" override guard is dead code).
- **Digit-penalty scoring** — `digit-penalty-score-adjustment`: `(1 − 1/len(basename))^digits` multiplicative decay applied at BOTH hybrid fusion and rerank ingestion; empty basename ⇒ literal 0.
- **Hybrid multi-query fusion** — `hybrid-search-multi-query-fusion`: `(lex + 2·vector)/3` with 0.04/0.02 floors for one-sided matches; k·3 over-fetch then position-decayed `1/2^j` fold privileging query #0.
- **Pointwise per-type rerank** — `pointwise-rerank-type-parallel`: no keys ⇒ identity; scores squashed ÷10¹² baseline; top-5 frozen ×1000 AFTER reranker writes; Cohere→Voyage key ladder; ThreadPoolExecutor per type with identical sequential fallback; percentile+score-floor cutoffs and empty→source fallback.
- **Streamable duality** — `streamable-function-duality`: plain call drains yields and returns StopIteration.value else last yield; `.stream()` exposes raw generator for UI consumers; returns are authoritative, yields advisory snapshots.
- **Plan continuation & repair** — `llm-plan-continuation-and-repair`: stop-token-bounded concatenating continuation (≤10 calls, tail-truncated resume prompt, cleanup-mutated history, swallowed continuation failures); ≤3-round index-addressed FCR repair with descending-order drops and filename-only COPIED_FROM_PREVIOUS_MODIFY overrides.
- **Sweep-PR cron maintenance** — `sweep-pr-cron-maintenance`: recency-capped `[:5]` scan of open bot-head PRs; base-into-head merge keeps bot branches current; `[Sweep Rules]` 24h-dirty close rule; Configure-Sweep-merged ⇒ create_gha_pr chain; per-PR fail-soft double except; dead `branch_ttl` clamp; unauthenticated external-cron GET.
- **Progress persistence plane** — `ticket-progress-persistence-plane`: delta-gated whole-doc `$set` upsert keyed on unique tracking_id (`model_dump == prev_dict` ⇒ no write); enum→value→enum round-trip; async saves share `global_threads`; `load` has no missing-doc guard; `wait()` breakpoint loop dead at pin.
- **Comment-header rendering plane** — `comment-header-rendering-plane`: pure-function header ladder (clamp → terminal index==4 bypass → percent math → error variant); two-layered old-PR deletion (literal `Fixes #N.\n` body marker + all-commits-by-bot veto, branch-only, one per run); issue-body regex pre-clean with `Branch:` override extraction.
- **Lexical index tokenizer & scoring** — `lexical-index-tokenizer-scoring`: identifier-fragment tokenizer (len≥2, letter-majority, uniqueness ratio <4) with content+CACHE_VERSION diskcache keys and pool-only-miss tokenization; tantivy empty-searcher retry loop (100× constant 0.01 s sleeps then raise); top-200 hits min-max normalized with all-equal⇒1.0 guard; basename-only repo identity in the cache key.
- **Vector embedding batch ladder** — `vector-embedding-batch-ladder`: cache-first per-text hash+version keys with send-only-misses and splice-with-assert; AWS SageMaker→Voyage→OpenAI(:512-cut) router all L2-normalized; split-in-half recursion on batch-token-cap errors vs truncate-to-8192 on per-text context errors; Timeout-only expo backoff (max_tries=5); asymmetric query/document input_type; provider-suffixed CACHE_VERSION namespace; dead Pool branch + dead chunk()/voyage-batcher helpers.
- **Context-pruning selection plane** — `context-pruning-selection-plane`: live surface = parse_query_for_files (full-path/URI-encoded/last-two-parts match, position-sorted, cap 5) → boost-after-last-mentioned protected prefix → rebind-not-append shared-list discipline → 2-level box-drawing import hierarchies (predecessors-at-root, fail-soft) → LLM file selection with whole-file rebuild + both-empty restore; the entire Claude rollout loop, reflections, and pagerank graph retrieval are DEAD at pin (early return + zero callers).
- **"Fixes #N.\n" marker contract & PR-summary ladder** — `fixes-marker-contract-and-pr-summary-ladder`: one byte-exact marker couples 2 writers (live PRSummaryBot.get_pull_request_summary + dead rewrite_pr_description twin) to 3 readers (literal+login-gate delete_old_prs, looser regex on_comment attribution, page-0 literal on_jira_ticket linking); writers split the marker across adjacent f-strings so a literal "Fixes #" grep finds only readers; :160 gate precedence quirk (missing title on attempts 0/1 crashes) + no break-on-success burns 3 LLM calls.
- **LLM file-selection budget plane** — `llm-file-selection-budget-plane`: interleave→test-partition→walk-down budget kernel (≤15 snippets, ±600-line cost form, first prefix ≤525k chars else raise)→unconditional reverse under dead `if True:`→XML prompt with double-expanded source (±900 rendered vs ±600 measured)→single gpt-4o call (pinned claude-3-opus silently overridden by use_openai)→strict filename-shape parse whose empty result is the safe default (caller restores pre-LLM context); msg.txt CWD debug writes at 3 plan sites.
- **Snippet annotation plane** — `snippet-annotation-plane`: tree-sitter ≤3000-char chunks → 4-worker haiku temp-0.2 annotations with whole-file-as-context prompt; every failure degrades to a literal placeholder (ticket never blocks); @file_cache key EXCLUDES issue_text (cross-issue sharing); reassembly via str.replace(count=1) on chunk text — identical chunks mislabel; read-only snippets rendered under the relevant_file template.
- **Test-editing variant plane** — `test-editing-variant-plane`: DEAD at pin (zero callers); inverted test/relevant partition, pre-render content swap from updated_files so the planner sees post-change code, fenced-diff framing of the fix as "what needs testing", one-shot continuation keyed on missing </plan> tag + length threshold, env-dependent model pin (claude-3-opus runs only when an Anthropic key exists) whose requested name is logged even when gpt-4o ran.
- **Jira multi-forge dispatch** — `jira-multi-forge-dispatch`: unauthenticated POST /jira spawns a detached thread and returns immediately; Jira ticket MIRRORED as a GitHub issue before the pipeline starts (forge-agnostic downstream); repo binding by `repo: org/name` regex in the body with silent return on miss; SYNCHRONOUS on_ticket ("# wait for this") so post-completion PR discovery (page-0 literal `Fixes #N.\n` marker, no bot-login gate) can see the result; zero try/except — failures die silently in the thread; no dedup/latest-wins on the second-forge path.
- **FCR application loop** — `fcr-application-loop`: 15-rounds-per-FCR hard budget; lazy fake-injected tool calls for compilable FCRs (planner output as executable program); system-only context reset gated on (change landed AND task advanced); identical-output dedup with one escalated retry then force-skip; MODEL==SLOW_MODEL no-op escalation at pin; formatter output accepted only if it does not revert all changes; use_openai force-false.
- **Search-and-replace match ladder** — `search-replace-match-ladder`: CRLF normalization → indent/rstrip search ladder → already-applied idempotency check → fuzzy did-you-mean (same-file score>80 with surrounding lines + bounded diff, then cross-file wrong-target scan) → occurrence enumeration with ±10-line context → replace(...,1) → baseline-relative lint/parse validation; every error message teaches the model's next call; attempt_count>5 force-skips the task.
- **FCR pre-validation plane** — `fcr-prevalidation-plane`: change-type flips against disk truth; suffix-match filename rescue; index-addressed errors with `<drop>` markers feeding the repair loops; ordered-plan escape hatches (previous-fcr containment, >50% line coverage) make sequential edits validatable without simulating them; tokenized fuzzy did-you-mean with parenthesis-superspan extension; brace-language-only parenthesis-mismatch check.
- **GHA planning variant body** — `gha-planning-variant-body`: content swap to post-change text before rendering; shared budget kernel; two-stage analyze→write ladder with in-place system-prompt swap and stop-tag-then-close; hardcoded use_openai=False in stage 2; ≤3 repair rounds validated against updated_files (positional) sharing the live planner's index grammar; RegexMatchError ⇒ ([], "").
- **Repo-parsing chunk plane** — `repo-parsing-chunk-plane`: cost-ordered exclusion ladder (suffix → parent-path-part → size 10 B–240 kB → decode → NUL bytes → avg-line>200 → token-density<2 on first 1 kB); scandir DFS pruning >240-child directories; path+content conditional-hash chunk cache (default 12000-char chunks vs the annotation plane's 3000); Pool(cpu//4) imap with stateless workers; single consumer prepare_lexical_search_index under two-tier (content-addressed + commit-addressed) caching.
- **Code-validation kernel** — `code-validation-kernel`: syntax-first ladder (tree-sitter + python ast fast path; unsupported ext valid by default) → pylint for .py (W0611 enabled only on the LAST fcr-for-file; crash degrades to empty) → eslint probe for js/ts (availability probe timeout=5 hard-fails with install instructions; run timeout=30 soft-fails) → everything else empty; baseline-relative comparison: capture before first edit, compare line counts after each, report only NEW errors (frequency≥2 pre-existing types suppressed, E-prefix always new, parse-error-cannot-get-worse); boolean is_worse_than has zero callers.
- **FCR grammar kernel** — `fcr-grammar-kernel`: one class-level `_regex` per entity + shared from_string (re.search DOTALL, groupdict construction, empty-capture→"", fail-loud RegexMatchError planners convert to safe-empty); closing-tag backreference forces the close tag to echo the change type; fixed attribute order; model-slop normalization (strip slashes, bullet rewrites, int coercion with a pin bug: bad end_line clears start_line); parse_fcr inner grammar (justification cut at first tag, "1."/"2." suffix hack, optional file_path/index attrs, strip_triple_quotes, replace_all by literal presence); COPIED_FROM_* substring markers keep large code out of repair-model context.
- **Chat-plane streaming jsonpatch** — `chat-plane-streaming-jsonpatch`: stream_state yields whole message-list snapshots (≤5 tool rounds, 50-char parse threshold, XML analysis/user_response/self_critique→role mapping, pending→complete function-call phases, stop-tag normalization + shared validate_and_parse_function_call); postprocessed_stream diffs snapshots into RFC 6902 patches with in-band error ops; final-message code_change blocks become FileChangeRequests validated by the ticket plane's get_error_message_dict — validated but NEVER applied (state stays pending).
- **Stateful suggestion streaming** — `stateful-suggestion-streaming-plane`: generate_code_suggestions renders done/processing/pending snapshots (done files carry full contents; pending carry first parsed pair + per-index error); @streamable duality serves create_pr's plain call and chat/api's modify.stream() JSON dumps.
- **XML tool-call parse twin** — `xml-tool-call-parse-twin`: registry-driven `<tool>(.*?)</tool>` parse with per-param regex; wrapper appends the stop-sequence-truncated `</function_call>` before parsing and patches chat_gpt.messages[-1] in place; missing params are a dispatcher-level teaching error, not a parse failure.
- **Repair-prompt corpus** — `repair-prompt-corpus`: every failure branch computes closest-correct context (fuzzy match + bounded diff, occurrence enumeration, counted parenthesis tallies) and attaches a numbered recipe prompt; latent pin bugs: missing {current_task} placeholders silently dropped by str.format, and `+ ... or fix_syntax_prompt` precedence makes fix_syntax_prompt unreachable; `<append>` flag is dead (not in tool_call_parameters).
- **Task-progress state machine** — `task-progress-state-machine`: done = content diff exists (never the model's claim); submit_task without changes burns done_counter (>3 forces DONE); attempt_count>5 force-skips the task; lazy application armed only on clean completion, disarmed by warnings/errors; annotation lies at pin (-> str returns int, -> dict returns bool).
- **Plan-context assembly** — `plan-context-assembly-plane`: replace-based (not str.format) template; one bucket per file with past/current/future tense lines; contents attach ONLY on the file's last FCR via get_latest_contents (mutated dict preferred over disk); reverse-order dedup quirk; relevant_modules validated against get_file_list.
