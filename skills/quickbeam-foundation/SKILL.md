## Capsule map
- **Runtime spine** — `runtime-genserver-ref-pending`, `script-load-handshake`, `handler-dispatch-task-salvage`, `server-macro-shared-clauses`: the GenServer/NIF protocol every JS call rides on.
- **Pool planes** — `pool-reset-reinit-checkin`, `context-pool-single-thread-multicontext`, `drain-callback-promise-pump`, `timer-min-dequeue-deadline`: heavyweight resettable runtimes vs lightweight multi-context threads, plus the concurrency tricks that make the latter correct.
- **Context lifecycle** — `context-lifecycle-rd-map`, `context-bytecode-cache`, `context-worker-bootstrap`: creation/teardown, cheap polyfill installs, Web-Worker emulation over child contexts.
- **Isolated VM subsystem** — `vm-isolation-spawn-opt`, `vm-event-loop-drive`, `vm-pin-store-lease`, `promise-resolution-state-machine`, `async-boundary-detach-resume`, `host-call-task-coordination`: pure-Elixir bytecode interpreter with spawn_opt containment, a no-polling event loop, a bounded pin store, the owner-local Promise resolution procedure, await as caller-stack split with depth rewind, and owner-monitored host-call tasks.
- **Invocation & exception protocol** — `invocation-call-classifier-actions`, `invocation-constructability-prototype`, `iterator-protocol-resumable-phases`, `exception-throw-unwind-catch-stack`, `exception-boundary-settlement-map`: the plan-don't-execute call classifier, constructability/prototype allocation, the resumable iterator protocol behind Promise combinators, catch-marker throw/unwind with convert-only-at-escape, and the per-boundary throw settlement table.
- **Value, property & heap plane** — `value-extended-number-coercion`, `value-utf16-wtf8-string-model`, `property-accessor-action-boundary`, `heap-compact-descriptor-dual-layout`, `memory-logical-charge-limit-ladder`: the canonical value algebra under every opcode, the WTF-8 string model, the accessor-action property boundary, the dual-layout object store with array/key-order semantics, and the logical memory budget that gates the whole interpreter.
- **Web API plane** — `fetch-httpc-sync-invert`, `url-component-contract`, `web-api-beam-backends`, `bundler-collect-rewrite`: browser-flavored APIs implemented as BEAM handler functions.
- **Error & boundary** — `js-error-dialect`, `beam-api-boundary-funcs`: exception translation and the misc BEAM function surface exposed to JS.
- **Compiled-execution tier** — `bytecode-envelope-checksum-varint`, `stack-verifier-dataflow`, `pure-profile-bounded-plan`, `compiler-contract-slot-pool-keys`, `compiler-pool-single-flight-lease`, `compiler-tier-action-algebra`, `compiler-deopt-validated-boundary`: the verify-first bytecode envelope, stack dataflow proof, bounded lowering to generated Elixir modules, atom-safe identity keys, single-flight leased module pool, and the validated deopt handoff back to the interpreter.
- **Generated-code install & ABI plane** — `code-emitter-form-envelope`, `code-import-closed-allowlist`, `code-artifact-digest-revalidation`, `code-lifecycle-soft-purge-slots`, `runtime-block-charge-exact-deopt`, `runtime-scalar-state-roundtrip`: bounded forms→binary emission, closed import allowlist, digest TOCTOU gate, soft-purge slot lifecycle, exact block charging, and the scalar compact-state round-trip across the versioned runtime ABI.
- **Pinned-program store plane** — `store-install-reserve-commit-recover`, `store-pin-single-flight-waiters`, `store-deferred-unpin-lease-gate`, `store-restore-namespaced-slots`, `store-residency-budget-no-eviction`: the store-side state machine behind `vm-pin-store-lease` — two-phase crash-safe install, single-flight pin admission via stored call waiters, lease-gated retirement, namespaced restart restore, and the three-tier residency budget.
- **Scalar profile & measurement plane** — `scalar-eligibility-ladder`, `scalar-block-charge-preflight`, `scalar-numeric-specialization-fallback`, `counter-owner-local-otp-counters`, `probe-space-saving-regions`: the tighter scalar lowering (tuple locals, per-block charging, guard-fallback specialization) behind the pure profile, plus the owner-local measurement trio it is instrumented with.
- **WASM plane** — `wasm-parser-section-finalize`, `wasm-import-rewriter-binary-surgery`, `wasm-api-handle-table-gen-server`, `wasm-js-value-marshalling`, `wasm-js-import-binding-exports`: the pure-Elixir disassembler (metadata + import oracle), order-validated import injection as binary surgery, the integer handle table bridging JS `WebAssembly.*` to NIF refs, the JS-side i64-as-BigInt/string value wire, and the JS-side import/export binding ladder with identity-preserving exports.
- **Web Locks plane** — `lock-manager-shared-exclusive-state-machine`, `locks-js-callback-release-contract`: the app-level shared/exclusive lock manager with holder-death recovery, and the JS-side finally-block release contract over the Beam.call outcome vocabulary.
