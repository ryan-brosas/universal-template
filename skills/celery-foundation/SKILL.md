# Celery: Distributed Task Queue Foundation

## Use this for
Use when building or porting a distributed task queue: deciding when a message is acknowledged vs requeued under every failure class (success, failure, timeout, worker death, connection loss), implementing manual and automatic retry with backoff+jitter, running a bounded process pool whose jobs are killed by soft/hard deadlines, composing a worker from ordered startable/stoppable bootsteps, scheduling delayed work on a timer, driving periodic tasks from a persistent scheduler, or controlling workers remotely via broadcast mailboxes. Source code and direct tests are ground truth; references carry decisive excerpts and graph retrieval.

## Capsule map
- **Execution spine** — `trace-execution-spine`: build_tracer closure caches everything hot; Reject/Ignore/Retry/Exception ladder maps to REJECTED/IGNORED/RETRY/FAILURE; redelivered+SUCCESS short-circuits via in-process set plus backend meta; callbacks dispatch before mark_as_done so children populate result metadata; EncodeError during store demotes to FAILURE; MemoryError always re-raised. `worker-state-ledgers`: requests dict + reserved/active WeakSets + successful_requests LimitedSet + revoked LimitedSet are the cross-bootstep ledger; maybe_shutdown() raises WorkerShutdown/Terminate from flags checked everywhere.
- **Retry & timeouts** — `task-retry-contract`: countdown defaults to default_retry_delay only when neither eta nor countdown given; max_retries exceeded raises original exc if provided else MaxRetriesExceededError; broker send failure becomes Reject(requeue=False); eager mode raises Retry for apply() to loop on. `autoretry-backoff-wrapper`: wraps run once (_orig_run sentinel); Ignore and Retry never retried; dont_autoretry_for beats autoretry_for; full-jitter exponential countdown from request.retries. `request-ack-matrix`: acks_late tasks ack on success/retry, ack-or-reject on failure per acks_on_failure/acks_on_timeout, reject(requeue=True) on worker-lost when reject_on_worker_lost; non-requeue Reject marks terminal FAILURE (#4222); hard-timeout path replays on_failure hooks inline and nulls exc.__traceback__ to break ref cycles. `asynpool-timelimit-trefs`: on_timeout_set arms soft then hard-minus-soft call_later chains keyed by job id in a WeakValueDictionary; _discard_tref swallows KeyError by design ("out of scope").
- **Pool** — `pool-base-worker-lost`: accept_callback(pid, monotonic) is the ack-late "started" signal source; propagate list lets WorkerShutdown/Terminate escape; BasePool contract = start/stop/apply_async/did_start_ok/maintain_pool/grow/shrink/terminate_job. `autoscale-scale-ladder`: body() sleeps 1s between checks; qty=len(reserved_requests) vs processes decides direction; update() shrinks BEFORE raising max_concurrency and adjusts consumer prefetch; ValueError from shrink means "all busy" — logged debug, not an error.
- **Boot & connect** — `bootstep-blueprint`: steps claim by qualname string, _firstpass pulls transitive requires into the same blueprint, DependencyGraph.topsort orders, single `last=True` step gets edges to everything and starts last; send_all(reverse=True) stops newest-first and propagates=False swallows per-step errors; stop() short-circuits unless fully started (state==RUN && started==len(steps)). `consumer-reconnect-loop`: recoverable_errors = connection_errors (+channel_errors when broker_channel_error_retry); restart_state.step() caps restart frequency (maxR=5/maxT=1) else sleep(1); EMFILE aborts hard; connection.collect(socket_timeout=5) prevents indefinite cleanup hang (#9705); broken connection closed HERE not in Connection.stop because graceful shutdown needs it for in-flight acks; optional cancel of active acks_late requests gated by worker_cancel_long_running_tasks_on_connection_loss; prefetch reduced by active_count*multiplier and restored lazily via promise .then on first ack after restart. `strategy-message-dispatch`: header['task'] → v2, payload decode → v1/hybrid, unknown type → reject + mark_as_failure(NotRegistered); expires/revoked checked before signals; eta converts to system/app tz timestamp for timer.call_at priority 6; bucket path requeues to head preserving order.
- **Heartbeat & gossip** — `event-heartbeat`: Heart binds start/stop to eventer.on_enabled/on_disabled so enabling events mid-run starts heartbeats; payload carries active count, processed counter, loadavg; heartbeat_sent signal fires only if receivers exist. `gossip-consensus-election`: worker-elect events heappushed as (clock, hostname.pid, topic, action) with immediate worker-elect-ack; leader decided by clock.sort_heap once replies >= alive_workers; winner runs its topic handler (e.g. call_task); periodic() evicts dead workers each interval.
- **Beat scheduling** — `beat-heap-scheduler`: heap holds (utc_timestamp, priority, entry); schedules_equal rebuilds the heap on any key/value change; pop→verify-is-event identity check defeats races; reserve() advances last_run_at/total_run_count BEFORE apply so failures don't reschedule forever; tick returns sleep hint capped by max_interval; should_sync flushes shelve by time or task count. `crontab-dst-schedule`: remaining_delta normalizes last_run_at AND now into schedule tz before field matching; execute_this_hour picks min minute > last minute else rolls forward; day-of-week uses isoweekday()%7 (Sunday=0); all-* fast path adds weeks, mixed fields use _delta_to_next; is_due with beat_cron_starting_deadline walks forward through missed runs keeping the LAST feasible one and refuses due if older than deadline.
- **Results & control** — `backend-chord-failure-propagation`: failure walks the whole chain deque, storing propagated states per element id, descending INTO chord bodies (#9674) and calling on_chord_part_return wherever 'chord' in options so nothing stalls; errbacks get (request, exc, traceback) when arity allows else legacy group(task_id) dispatch; NotRegistered errbacks fall back to async send. `result-backend-state-contract`: every write funnels through encode_result→_store_result with an optional always-retry ladder; PENDING means no-record; only FAILURE/REVOKED propagate on .get(); foreign exceptions degrade to fabricated subclasses. `redis-backend-retry-policy`: retry_policy merges base + transport_options overrides; ensure() wraps _store_result ops in kombu retry_over_time with E_LOST logging; value writes enforce size cap then pipeline(setex/set + publish); add_to_chord is a bare INCR on `<key>.t`. `control-panel-mailbox`: Panel.data is a global name→handler dict registered via decorator with metadata (visible, default_timeout, help); revoke flags ids into worker_state.revoked AND best-effort backend.mark_as_revoked, terminate fans into matching active requests by signum; Pidbox listens on per-host queue forwarding clock on every message. `revoke-plane`: pre-execution screening (already-revoked latch → expiry → id set → stamped headers); announcement = task_ready + event + backend mark + ACK in order; terminate-before-start defers via _terminate_on_ack.
- **Producer & cluster** — `publish-retry-delayed-delivery`: publish merges default+custom retry_policy and converts direct-no-routing to anon exchange; quorum-queue countdowns reroute through celery_delayed_N topic ladder with queue popped; per-URL setup tolerates partial failure but criticals when all fail. `mingle-startup-sync`: 1s-timeout hello broadcast imports peer clocks (adjust=max) and revoked sets; alone-is-normal. `dedup-on-redelivery`: redelivered-only check, local set then backend meta, fail-open on read errors, children-marker-guarded callback repair, Reject(requeue) relying on broker DLQ as circuit breaker.
- **Throttle & lifecycle** — `rate-limiter-token-bucket`: bucket FIFO drains while tokens last, refusal requeues to HEAD preserving order, timer re-arm at expected_time with rotating priorities; eta+bucket holds qos slot until both clear. `shutdown-ladder`: warm stop closes consumer first then reverse-order blueprint teardown under a 5s socket timeout; soft shutdown waits a bounded window for actives; cancellation matrix spares successful-unacked tasks and flips emit_retry off for acks_late.
- **Loop & sync** — `event-loop-selection`: async-transport+POSIX picks hub-driven asynloop with DummyLock qos; AMQP heartbeat ticks live on the shared timer capturing errors by reference; gevent connect-timeout defensive quirk; did_start_ok gated to first start only.
