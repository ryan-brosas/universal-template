# Cuga Agent Foundation

## Use this for
Use when adding a policy/governance layer to an LLM agent graph: blocking intents with custom responses, injecting playbook guidance into prompts, enriching tool descriptions, requiring human approval before generated code runs, reformatting agent output, enforcing admin-authored guard code around tool calls at the provider boundary — and generating that guard code from policies at build time, persisting policies over vector stores or markdown folders, carrying cross-turn budgets through checkpointed state, and exposing an auditable decision trail — all inside one LangGraph `StateGraph` whose nodes read the policy system from `config["configurable"]`. Source code and direct tests are ground truth; references carry decisive excerpts and graph retrieval.
