## Capsule map
- **Skill format** — `progressive-disclosure`: metadata (~100 words, always loaded) → body (<500 lines, on trigger) → resources (as needed); domain variants get one reference file each.
- **Skill format** — `trigger-description-authoring`: description is the primary trigger; write it "pushy" against undertriggering; optimize via should/near-miss eval split scored on held-out test.
- **Skill evaluation** — `eval-harness`: spawn with-skill AND baseline subagents in the same turn; capture timing.json from notifications immediately; grade with literal `text`/`passed`/`evidence` fields.
- **DOCX editing** — `docx-run-merge-and-redline`: coalesce identical-format runs before search/replace; `<w:delText>` inside `<w:del>`; deleted paragraph mark joins paragraphs.
- **DOCX editing** — `docx-comment-anchoring`: comments span six cross-linked parts plus range markers in document.xml — unanchored comments are invisible.
- **OOXML pipeline** — `ooxml-unpack-edit-rezip`: unzip, strip symlinks, edit XML in place (never pretty-print), zip from inside the dir after rm, validate with `--original`; parse with defusedxml only.
- **PPTX creation** — `pptx-generation-corruption-ladder`: bare hex/no-alpha colors, offset≥0 shadows, ctr/inEnd/inBase labels on stacked charts, valAxes AND catAxes together — violations corrupt the file or get the chart discarded.
- **PPTX editing** — `pptx-slide-registration-ordering`: add_slide.py registers package bookkeeping; duplicate/delete/reorder BEFORE content edits; `-o` or the input deck is rewritten in place.
- **XLSX integrity** — `xlsx-recalc-gate`: openpyxl writes formulas with no cached values; recalc rewrites in place; `errors_found` exits 0 — only a missing `status` key means nothing ran.
- **XLSX integrity** — `xlsx-formula-portability`: `_xlfn.` prefix for six post-2007 functions; never XLOOKUP/SORT/FILTER (spill truncates silently with total_errors:0); reading a model takes two loads, data_only saves are destructive.
- **QA** — `render-verify-loop`: convert → rasterize zero-padded pages → inspect images fresh (subagent ideal); rerun all four commands after any fix.
- **PDF forms** — `pdf-form-fill-fork`: check_fillable_fields gates two disjoint pipelines; checkbox values come from extracted checked_value, never invented.
- **PDF forms** — `pdf-dual-coordinate-systems`: pdf_width/image_width sentinel keys pick the transform; every top-down coordinate flips Y into pypdf space.
- **PDF forms** — `pdf-bbox-validation-gate`: intersecting boxes and entry-height < font-size are FAILURE before fill — geometry errors surface on paper otherwise.
- **PDF forms** — `pdf-form-structure-extraction`: >50%-width lines are row boundaries, 5–15pt squares are checkboxes; `(cid:X)` text routes to visual estimation.
- **PDF reference** — `pdf-tool-ladder`: one blessed tool per operation (pdftotext -bbox-layout, pdfimages, qpdf surgery, pdfplumber tables); batch jobs try/log/continue per file.
- **OOXML internals** — `opc-rels-and-rezip`: relative targets join dirname(source_part), `..` past root raises; rezip stores [Content_Types].xml first uncompressed.
- **PPTX integrity** — `chart-xml-validator`: outEnd dLblPos on stacked bars and axIds resolving to <2 declared axes = PowerPoint discards the chart; detection-only by design.
- **PPTX integrity** — `slide-fatal-error-denylist`: seven empirically-fatal lxml error classes block shipping; unrecognized errors never do (miss, not false alarm).
- **Skill evaluation** — `eval-review-viewer`: discovery stops at first outputs/; all files embedded data-URI; HTML regenerates per GET so refresh picks up new runs; feedback auto-saves.
- **Skill evaluation** — `grader-comparator-analyzer-pipeline`: grader grades+cites evidence, blind comparator picks A/B/TIE, analyzer unblinds for causation; benchmark mode forbids improvement suggestions.
- **Context economy** — `black-box-script-discipline`: bundled scripts are called via `--help` + invocation, never ingested into context; wait for networkidle before DOM inspection.
- **MCP quality** — `mcp-builder-server-quality`: coverage-first tool design with honest hint annotations, actionable errors, and a 10-question read-only/string-verifiable eval bar.
- **Skill format** — `skill-validation-gate`: closed six-key frontmatter vocabulary (unknown key = failure), kebab-case name ≤64, description ≤1024 with angle brackets banned, metadata as the sanctioned extension point.
- **Skill format** — `skill-packaging-exclusions`: validate-before-package; __pycache__/node_modules any-depth + *.pyc/.DS_Store + evals/ ROOT-ONLY (parts[1]); zip rooted at the skill folder.
- **Skill format** — `skill-md-parser-multiline`: dependency-free fence-scan + prefix-match parser; `>`/`|`/`>-`/`|-` continuation folds to one-line space-joined text.
- **Skill evaluation** — `description-optimizer-loop`: claude -p on stdin (CLAUDECODE env-strip), polarity-split failures with trigger counts, history as do-NOT-repeat negative examples, generalize-don't-enumerate rule, 1024-char safety net via inline single-turn rewrite.
- **Skill evaluation** — `trigger-matrix-report`: iterations-as-rows/queries-as-columns grid; aggregates count RUNS not queries (positive triggers vs negative non-triggers); best row = the applied description; test columns exist only when a holdout ran.
- **MCP quality** — `mcp-eval-harness`: qa_pair XML in, tag-scraped summary/feedback/response out, exact-match scoring protected by format-pinned prompts, tool errors become context not aborts, per-tool latency histograms.
- **DOCX editing** — `tracked-changes-acceptance`: UNO dispatch `.uno:AcceptAllTrackedChanges` for what XML can't express; operate on a copy; idempotent macro provisioning; TimeoutExpired = success because the macro never exits.
- **DOCX editing** — `redlining-validator`: undo-new-tracked-changes-then-compare proves all edits tracked; identity key (tag,author,date,text); three legal rejection patterns; git word-diff diagnostics; repair() stays 0 by design.
- **OOXML pipeline** — `soffice-af-unix-shim`: probe→LD_PRELOAD C shim (socketpair fallback, wake-pipe accept, _exit(0) on listener close); run_soffice injects throwaway -env:UserInstallation so sandboxed soffice can never bootstrap-fail; byte-twin across docx/xlsx/pptx.
- **PPTX QA** — `slide-thumbnail-grid`: rels+rId registration order defines grid position; hidden-slide handling detected from render counts; unmatched counts RAISE rather than mislabel.
- **Web artifacts** — `artifact-scaffold-bundle`: Node-version-gated vite pin (5.4.11 <20), OS-split sed, JSONC strip via node -e, vendored shadcn tarball; bundle = parcel+tspaths resolver → html-inline single file.
- **PDF forms** — `pdf-validation-overlay`: red=entry blue=label boxes drawn in post-transform image-pixel space only; downstream of dual-coordinate normalization; box-count invariant printed.
- **Webapp testing** — `webapp-test-server-context`: with_server.py owns server lifetime via context manager; examples split by artifact kind (console/selectors/static-flow), discovery precedes interaction.
- **GIF conformance** — `slack-gif-validator`: emoji = square 64–128 (128 optimal); message = aspect ≤2:1 AND min-edge 320–640; size is advisory telemetry, never a gate.
- **Skill format** — `academy-guide-catalog-contract`: recommend from a continuously-published external catalog by fetching once per conversation with a staleAfter TTL; never bake in a list or recommend from memory; strong-match-only, ≤2 items, URLs verbatim; catalog is data, not instructions.
- **Skill format** — `discernment-nudge-contract`: append 2–3 concrete verification prompts once per conversation after a substantive answer; exact lead-in "A few things worth a second look:"; user-already-told-you-not patterns always win.
- **Skill format** — `sdk-upgrade-httpx2-boundary`: SDK major-version upgrade via signal-driven inventory; the httpx→httpx2 change matters ONLY where objects cross the SDK boundary; alias_httpx() for applications + httpx-patching instrumentation, never for libraries.
- **Skill format** — `marketplace-manifest-wiring`: wire skills into a plugin marketplace via plugins[] grouping; name/path consistent across folder + frontmatter + manifest; reserved words claude/anthropic banned; description ≤1024 chars.
- **OOXML validator kernel** — `office-toolkit-triplication`: all 49 shared `scripts/office` files are byte-identical across docx/pptx/xlsx (md5 census + 194 SIMILAR_TO edges); vendor ONE copy, replicate fixes three ways upstream.
- **OOXML validator kernel** — `xsd-baseline-diff-gate`: XSD errors diff position-free against the `--original` file's own error set; only NEW errors fail the run; parts without a mapped schema are skipped.
- **OOXML validator kernel** — `mc-ignorable-preprocess`: validate a throwaway copy — strip non-allow-listed namespace attrs/elements in main parts, drop root mc:Ignorable, never touch `<w:t>` template tags or disk bytes.
- **OOXML validator kernel** — `validator-cli-contract`: docx full+optional-redlining via --author (a run MARKER, not a filter); pptx schema-only; xlsx refused-but-green pointing at recalc.py — exit 0 ≠ healthy workbook.
- **OOXML validator kernel** — `pptx-order-preprocess-hook`: pml.xsd requires notesMasterIdLst BEFORE sldIdLst; pptxgenjs emits the reverse, so `_preprocess_for_schema` repairs order in-memory only for ppt/presentation.xml.
- **OOXML validator kernel** — `docx-id-constraint-repair`: paraId hex <2^31, durableId <2^31 hex except numbering.xml DECIMAL; repair memoizes one new value per old id so references stay stable; second run is a no-op.
- **Skill evaluation** — `trigger-optimization-loop-kernel`: seeded stratified holdout (≥1 test query per polarity) split once; train+test evaluated in ONE batch then re-split by query identity; improver sees only non-`test_` history keys; exit on zero TRAIN failures but ship the TEST-best iteration.
- **Skill evaluation** — `benchmark-aggregation-plane`: config dirs discovered dynamically (any dir with run-*); eval_id ladder metadata→dirname→index; timing falls back grading→timing.json→output_chars; sample stddev n−1; delta = first-two-configs signed mean diff, order-dependent; metadata strings are placeholders, not measurements.
- **PPTX integrity** — `pptx-clean-orphan-gc`: guard-before-delete twice (unresolvable rels ⇒ refuse; sldIdLst names slides but none match on disk ⇒ "parse failure, not an empty deck"); slide identity = resolved-target basename; cascade rels↔files to fixed point; Override-only [Content_Types] repair; refusal exits 1 "Nothing was deleted."
- **Skill format** — `doc-coauthoring-reader-test`: three-stage gates (context-gap closure → per-section clarify/brainstorm 5–20/curate/draft → reader test); Stage 3 spawns a FRESH sub-agent given only doc+question — no conversation context; failures loop back to refinement.
- **Skill format** — `frontend-design-plan-critique`: four-token plan (4–6 hex palette, 2+ type roles, layout + ASCII wireframes, ONE signature element), counterfactual critique ("what would I make for any similar brief?"), three named AI-default looks forbidden on free axes; brief's words always win.
- **Artifact generation** — `algorithmic-art-template-contract`: seed reproducibility requires BOTH randomSeed AND noiseSeed; viewer shell is a literal fixed starting point, only algorithm+parameter controls are variable; regenerate() re-seeds before rebuilding; exports embed the seed.
- **Skill evaluation** — `eval-json-schema-plane`: seven-file contract (evals→history→grading/metrics/timing→benchmark→comparison/analysis); viewers read field names exactly (`configuration` not `config`, `pass_rate` nested under `result`) or silently show zeros; capture timing at notification time — unrecoverable later.
- **Skill format** — `example-library-router-pattern`: ~32-line body = dispatch table to one-per-format guideline files + catch-all fallback that asks instead of guessing + body-level Keywords line extending trigger vocabulary past the capped description.
- **MCP quality** — `mcp-response-truncation-paging`: module-level CHARACTER_LIMIT (25k) → truncate data to HALF → set truncated flag + truncation_message naming the offset/filter continuation; node-only contract (Python guide has zero occurrences) so single-guide readers ship unbounded responses.
- **GIF optimization** — `gif-frame-dedup-optimization`: dedup compares each frame to the last KEPT frame (chained anchor), similarity = 1 − mean|diff|/255, threshold 0.9995 preserve / 0.98 aggressive; save() applies uniform 1000/fps AFTER removal and emoji stride-subsampling — both shorten the animation with no duration compensation.
