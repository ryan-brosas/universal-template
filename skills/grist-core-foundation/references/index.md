# Grist Core Foundation

## Use this for
Use when porting Grist's server infrastructure onto your own stack — a single-file document storage engine over embedded SQLite (dynamic-typed values, live schema evolution, big filtered reads, attachment blobs), reliable outbound webhook/event delivery from a collaborative document store, per-resource background work (flush/prune/save), multi-worker doc placement on redis, short-lived machine authorization, auditable net-change summaries over action logs, cross-process cache coherence, and sandbox CPU governance without cgroups. Source code and direct tests are ground truth; references carry decisive excerpts and graph retrieval.
