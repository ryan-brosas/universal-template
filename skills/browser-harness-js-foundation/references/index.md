# Browser Harness JS Foundation

## Use this for
Use when attaching an LLM to a real Chromium over raw CDP without a wrapping framework: auto-discovering running browsers via DevToolsActivePort, holding one persistent session behind a stateful HTTP eval daemon, compressing accessibility trees into actionable snapshots with refs/locators, observing user input cross-tab, recording consent-gated privacy-scrubbed action traces, compiling them into provenance-sealed explanatory videos, shipping per-site recipe registries and bash-heredoc skill CLIs — or keylessly extracting the data behind bot-walled surfaces (Google search/news/Maps incl. directions + TSP ordering, X timelines, Reddit JSON) and browser-natively capturing YouTube/TikTok media by recording what the player feeds MediaSource (no yt-dlp, no signature solvers). Source code and direct tests are ground truth; references carry decisive excerpts and graph retrieval.
