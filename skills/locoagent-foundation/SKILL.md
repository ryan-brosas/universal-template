# LocoAgent: Browser-Operating Agent Foundation

## Use this for
Build or port an agent that autonomously operates real web accounts through a dedicated CDP Chrome: bring up isolated persistent browser profiles, run deterministic (LLM-free) browser pipelines under an agent's supervision on schedules, serialize access per platform across OS processes, deduplicate irreversible actions across sessions, inject live operational state plus hard safety rules into an LLM system prompt, load layered AGENT.md-style instruction memory with @includes, generate deterministic per-user personas/sprites — and (pass 25) port a global session-state singleton with import-safe cycles, atomic session-identity switching, cache-stable beta-header latching, and cursor-paginated remote history. Source code and direct tests are ground truth; references carry decisive excerpts and graph retrieval. The repo is a Claude Code CLI fork with a thin LocoAgent layer (`scripts/`, `workflows/`, `skills/x-com/`) plus eight mined upstream subsystems (`src/utils/agentmd.ts` memory loading, `src/buddy/` companion generation, the pass-11 dynamic-context plane: `src/utils/attachments.ts` + `src/context.ts`; the pass-12 turn-loop/recovery plane: `src/query.ts` + messages normalization; the pass-13 execution/producer planes: tool funnel + StreamingToolExecutor + hook core, microcompact producers, API streaming/retry producer; the pass-14 chrome-integration plane: `src/utils/claudeInChrome/` native-messaging bridge + extension detection + in-process MCP server; and the pass-14 compaction-producer plane: `src/services/compact/compact.ts`; the pass-15 swarm/teammate plane: `src/utils/swarm/` leader-teammate orchestration — backend detection/lifecycle, in-process runner, mailbox-driven permission sync; and the pass-16 remote-control bridge plane: `src/bridge/` multi-process session transport — work-poll dispatch, JWT refresh scheduling, v1/v2 transport adapters, crash-recovery pointers, fault injection; and the pass-26 session-transport plane: `src/cli/transports/` env-gated read/write topology selection, WS/SSE/Hybrid transports with resumable sequence reads and confirmed-eviction replay, one serial batch uploader, one coalescing worker-state uploader). Upstream tests are `bun:test` colocated under `scripts/`; the transports plane ships no unit tests, so its probes cite decisive source lines deterministically.
