### Scenario D: ambiguous dashboard regression — 6/6, pass

1. **Evidence:** separated observed metrics, reported tickets, deterministic event renaming, and assumed Hick’s-law cause; framed “find and open the intended report.”
2. **Differential:** preserved instrumentation drift, missing capability, weak scent, hidden mobile navigation, broken expert path, and genuine choice cost.
3. **Disconfirmation:** required common event reconstruction, old/new reproduction, ticket coding, and unprompted first-click/task evidence before accepting choice overload.
4. **Intervention:** mapped each possible finding to a bounded treatment; preserved keyboard and mobile behavior; rejected arbitrary 50% removal.
5. **Comparison/guardrails:** defined segment-specific completion, correctness, abandonment, accessibility, support, and a practical recovery rule; recognized faster time as ambiguous.
6. **Decision:** explicit restore/rollback, keep, revise, or instrumentation-only outcomes, including immediate rollback for blocked mobile/keyboard access.

No hard fail. Strongest phrase: “Hick’s law is a hypothesis about choice effort, not proof that option count caused this regression.”

### Scenario E: high-stakes AI recommendation — 6/6, pass

1. **Evidence:** separated completion metric, older-user reports, hidden confidence/exclusions, heuristic default-inertia inference, and unknown suitability/enrollment causes.
2. **Differential:** retained explanation/recovery, automation overreliance, and nonpersuasion readability/data/enrollment defects.
3. **Disconfirmation:** required support/change audit, system verification, counterbalanced comparison, and precommitment teach-back.
4. **Intervention:** replaced unearned “Best for you,” removed passive preselection, surfaced basis/limits/costs/alternatives, preserved human help, and specified apply/adapt/reject.
5. **Comparison/guardrails:** included older adults, insurance literacy, assistive use, interruption, and 7-/30-day/change-window outcomes.
6. **Decision:** explicit keep/expand, revise, revert, and stop/escalate criteria; completion could not override misunderstanding or costly harm.

No hard fail. Strongest phrase: “A completion increase alone must never pass this decision gate.”

## Limits

These are model-behavior probes, not evidence that a product intervention works. The model family used for the historical GREEN also authored parts of the procedure, and the reviewer is not fully independent. Re-run with a different model/reviewer after material changes; retain revision-bound response artifacts and failures, not only passes.
