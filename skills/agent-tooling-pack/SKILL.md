# Agent tooling pack

Choose the matching integration procedure, not a default engineering workflow;
resolve its paths from its own directory. Installed runtime guidance and live
schemas own the API; do not load a different kernel's instructions.

- AppFlowy workspace organization, numbered pages, native calendars, record updates or recovery:
  [appflowy-workspace](../../knowledge/playbooks/appflowy-workspace/README.md).
- Pi package manifests, extensions, packaging or missing pi.dev listings:
  [pi-package-development](../../knowledge/playbooks/pi-package-development/README.md).
- Work-time extension deployment, interval evidence and confirmed hours drafts:
  [work-time-tracking](../../knowledge/playbooks/work-time-tracking/README.md).
- Isolated agent workers timing out, truncating replies or rejecting background jobs:
  [managed-agent-runtime-diagnostics](../../knowledge/playbooks/managed-agent-runtime-diagnostics/README.md).
- OpenCode MCP servers failing to connect, timing out during local `npx` startup,
  or requiring authentication:
  [opencode-mcp-diagnostics](../../knowledge/playbooks/opencode-mcp-diagnostics/README.md).
- Choosing among OpenCode subagents or maintaining the `agents/` roster:
  [subagent-delegation](../../knowledge/playbooks/subagent-delegation/README.md).
- Adding or verifying a local OpenAI-compatible gateway as a provider:
  [local-gateway-providers](../../knowledge/playbooks/local-gateway-providers/README.md).
- Measuring or improving prompt-cache hit rate across sessions:
  [prompt-cache-efficiency](../../knowledge/playbooks/prompt-cache-efficiency/README.md).
- Provider authentication, model catalogs and runtime behavior:
  [pi-provider-contracts](../../knowledge/playbooks/pi-provider-contracts/README.md).
- Fabric execution, tool availability, durable actors, and transactional
  boundaries:
  [fabric-native-execution](../../knowledge/playbooks/fabric-native-execution/README.md).
- Bounded semantic triage with a typed judge, including Jev, and portability
  between hosts:
  [typed-judgment-workflows](../../knowledge/playbooks/typed-judgment-workflows/README.md).
- Agent-team delegation, durable coordination, task learning, and workspace moves:
  [autonomous-agent-teams](../../knowledge/playbooks/autonomous-agent-teams/README.md).

For judge calibration or other distinct integration questions, select additional
[agent-tooling topics](references/topics.md); do not load the index recursively.

The host chooses which model runs. This pack does not rank models or route tasks.
Do not install or configure an external planner just to answer an ordinary
planning question.
