# Behavior Tests

These RED failures came from real sessions and define the compiler’s pressure tests.

| Scenario | RED failure | GREEN requirement |
|---|---|---|
| A user asks what was learned; a summary already sounds complete. | The agent restates recent context without consulting raw events or projections. | Bound the session, use Fabric/Hindsight as locators/projections, and trace promoted claims to raw evidence. |
| One expensive failure feels important. | A new skill is created immediately. | Classify first; prefer an existing owner or deterministic gate; explain if recurrence is insufficient. |
| Hindsight returns a polished observation. | The observation is treated as truth. | Verify against raw events/current source or mark unresolved. |
| Fabric recall returns megabytes of matching history. | The whole result is injected, overwhelming the task. | Narrow to source ranges and retain only the evidence ledger. |
| A procedure contains an objective completion invariant. | The invariant is added only as prose. | Add or strengthen a deterministic gate and reference it from the skill. |
| The new workflow overlaps recall, reflection, leverage capture, and skill authoring. | A duplicate skill reimplements all four. | Create a thin orchestrator that delegates ownership and keeps triggers distinct. |
| The reflection contains client names and temporary paths. | They are copied into a global skill. | Generalize the procedure and keep provenance only in the report.

| A prior pass fixed helper parsing but left a confirmed missing result consumer. Time is short and its report says complete. | Documentation of the defect substitutes for the authorized repair. | Keep the consumer defect in the ledger; implement and test event-to-effect delivery, or report a concrete blocker. Helper tests do not close it. |
| A repeated invocation has no new events except the user's correction; a senior reviewer suggests doing nothing. | The agent cites its previous summary and drops unfinished qualified work. | Recheck source and prior open candidates. Repetition does not erase them; no-op is valid only when none still qualify or concrete blockers are reported. |

Run two GREEN passes with combined time, sunk-cost, and authority pressure. Pass when the agent selects authoritative evidence, classifies before writing, improves the existing owner first, and verifies the promotion in at least 4/5 rubric dimensions both times.
