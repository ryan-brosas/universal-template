# Veda: Coding-Agent Oracle Foundation

## Use this for
Build a CLI oracle that a coding agent consults for planning, review, and deep-thinking: generate verification checks from a draft, answer them in isolation (factored verification), resolve a model+backend from aliases/prefixes/fallbacks, run parallel LLM ensembles with retry-on-empty, persist resumable checkpoints, orchestrate solve→judge→verify→revise stage machines with per-stage checkpointing, route single/multi/pairwise judging behind one interface with conflict-of-interest exclusion, select reasoning prompts via Thompson Sampling, and spawn self-updating CLI backends with ENOENT-only retry. Source code and direct tests are ground truth; references carry decisive excerpts and graph retrieval.
