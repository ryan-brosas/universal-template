## Capsule map
- **Search modes** — `search-modes`, `local-search`, `context-builders`, `mixed-context-substitution`: Map-Reduce/local/DRIFT/basic queries over assembled, budgeted graph context; LLM-rated community preselection; report-for-context substitution under budget.
- **LLM infrastructure** — `llm-completion-pipeline`, `sliding-window-rate-limiter`, `completion-threading`, `token-chunking`, `derive-from-rows`, `llm-gleaning-loop`, `description-summarization`, `streaming-embed-text`, `extraction-prompt-budget`, `prompt-tune-generators`, `prompt-tune-selection`: injected-concern completion calls, dual-window throttling, threaded concurrency, token-accurate chunking, collect-then-throw fan-out, gleaning loops, rolling-partial summarization, streaming embeddings, budgeted few-shot packing, prompt-tuning bootstrap + corpus selection.
- **Storage & state** — `storage-abcs`, `incremental-pipeline`, `stream-finalize`: swappable backends with child() scoping; delta indexing with backup-before-merge; natural-key dedup + FINAL_COLUMNS projection.
- **Monorepo seam & config** — `architecture`, `config-model`: capability-seam package split; named models + per-feature sections.
- **Graph extraction & clustering** — `graph-merge-orphan-filter`, `cluster-graph-determinism`, `lcc-union-find`, `prune-graph-ladder`, `noun-graph-nlp`, `community-report-pipeline`, `claim-extraction`: pair-keyed merge with orphan guard, deterministic Leiden, union-find LCC, ordered pruning, no-LLM noun co-occurrence graphs, bottom-up report hierarchy, covariate tuples.
- **Workflow orchestration plane** — `pipeline-factory-registry`, `workflow-function-contract`, `streaming-table-workflow-idiom`, `community-assembly-workflow`, `embedding-field-dispatch-workflow`, `report-context-prep-workflow`, `update-chain-workflows`, `extraction-workflow-guards`: registry-selected pipelines over a uniform run_workflow contract, streaming-table idiom with same-file safety, cluster→community assembly, config-driven embedding dispatch, twin report context builders, and the eight-step incremental update chain with state-key handoffs.
- **Agent-driven dependency automation plane** — `dependabot-suppression-closure`, `agent-assigned-sweep-issue`, `update-deps-skill-contract`, `migration-gotchas-ledger`, `weekly-deps-choreography`: paired Monday cron workflows close all Dependabot PRs (collect-all-then-close) and open one Copilot-agent issue pointing at the repo-owned update-deps skill; the skill fences release-owned lines and a golden-data pin, backed by a verified migration-gotchas ledger.
- **Vector filtering & schema plane** — `vector-filter-algebra`, `filter-f-builder`, `timestamp-explosion-fields`, `vectorstore-abc-hooks`, `lancedb-filter-compiler`, `index-schema-guard`: one pydantic filter algebra shared by humans and LLMs, write-time timestamp component explosion, base-class/backend method split, per-backend compilation, and identifier guarding.
- **Shared factory kernel** — `singleton-service-factory`: the graphrag-common Factory ABC every side package's `{x}_factory.py` subclasses (transient/singleton scopes over canonical arg hashing).
- **Graph metrics plane** — `dataframe-modularity-nx-parity`, `stable-lcc-components`: NX-parity modularity and row-order-stable connected components/LCC on plain DataFrames (pinned-seed determinism carried from cluster-graph-determinism).
- **Query assembly plane** — `indexer-adapters-rollup`, `query-api-surface`, `search-engine-factory-wiring`, `question-generation`: parquet→model adapters with community roll-up, paired streaming/collected API surface, engine construction wiring, follow-up question generation.
- **Status logging & API edge** — `blob-workflow-logger`, `status-wiring-initloggers`, `index-build-api`, `common-config-loader`, `llm-response-gather-utils`, `reformat-context-contract`: durable append-blob log sink with safe rotation, registry-selected reporting sinks wired once across package namespaces, the index-side orchestration shell feeding the pipeline factory, the shared settings-loading ladder, stream-gather/structure kernels behind every fan-out, and the fixed-five-key response normalizer.
