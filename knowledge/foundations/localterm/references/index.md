## Capsule map
- **Bash-secret defense** — `secret-defense`: scrub child env at spawn (pure), stream-redact output with full-value overlap hold-back; values from process.env via validated names-only policy files.
- **Terminal stack** — `terminal-pty`, `architecture`: node-pty sessions with out-of-band metadata channels, 64K atomic frames vs 100ms-classified streams, brotli-context-takeover transport, daemon-answered kitty probes, identity-stripped PTY env, replay-through-exec shell hooks.
- **Session management** — `session-manager`: daemon-owned PTY registry with a grace window between "last viewer left" and "shell dies"; every id-based op funnels through one not-found tenant gate. `session-multi-client`: per-client pending→promote state machine (replay-end always sent), one resize owner + one terminal responder chosen by activity recency. `session-lifecycle`: reap only on true idle (no clients + no output + no foreground) via fire-time re-check; evict-oldest-dormant at the cap, pinned exempt.
- **Headless rendering & persistence** — `capture-renderer`: one async parser write in flight, UTF-8-byte-accurate queued backlog feeding PTY flow control, sequence-scoped flush barriers, marker-row exec extraction with -1 fallbacks, SGR-only newest-rows-first normal-buffer snapshots. `hibernate-store`: versioned strict-schema file, fail-open reads (any anomaly ⇒ []), atomic 0o600 writes, control bytes never persisted.
- **Agent extension** — `agent-integration`: set TUI capabilities before the first query; notify only on settled ≥30s turns through sanitized OSC 9; re-bake user settings when overriding a tool by name.
- **CLI ergonomics** — `cli-fast-path`: bin imports a tiny argv gate before the framework; exact-shape hits dynamic-import the real command (byte-identical stdout/exit), misses lazily import the full program.
- **Agent automation** — `exec-marker-protocol`: marker-token exec inside a shared interactive shell with raw-stream exit-code recovery, timeout→Ctrl-C→grace, and ephemeral-renderer extraction. `wait-ladder`: block until pane matches text/regex or goes idle — flush-before-read predicate evals on output events, recency idle poll, one finalize for match/timeout/exit.
- **Git & UX surfaces** — `git-diff`, `completion-theme-fonts`, `reuse-guide`: path-keyed diff pipeline with byte caps, exact-or-throw patch reversal, declarative completion specs, one-source theme/font catalogs.
- **Daemon power keep-awake (caffeinate)** — `caffeinate-automatic-detection`: automatic mode engages on a shell-hook foreground-name match (no `ps`) else a BFS walk under session shells; activity gate requires recent output and releases via a trailing-edge timer that arms only when a gated program is the SOLE reason active; a peer client holds independently, bypassing the gate. `caffeinate-battery-guard`: every activation funnels through one shouldActivate gate with a fail-open suppression latch, an immediate first probe, adaptive delays (half interpolated time-to-threshold clamped [5s,15min]), and MAX-interval retry after failed reads. `caffeinate-trigger-matcher`: whole-segment basename/extension/path matching so `pi` never matches `raspimon`; roots never match themselves. `caffeinate-controller-spawn`: ONE keep-awake process, identity-checked exits distinguish unexpected death from intentional stop, Linux spawns detached + group-kills systemd-inhibit's forked tail. `caffeinate-battery-parse`: pmset/sysfs → `{percent, isOnBattery, minutesToEmpty}` where AC "remaining" is time-to-charge and malformed reads are null, never 0%. `caffeinate-preferences-migration`: version-stepped v1→v4 migration in front of strict zod so upgrades never reset user settings; tmp+rename writes. `caffeinate-wiring`: SessionManager hooks are the event source; one recompute funnel composes mode∧detection∧battery into controller.setActive; change events rebroadcast to every tab.
- **Scheduled automation kernel** — `cron-kernel`, `schedule-compile-recognize`, `minute-ticker-scheduler`: a zero-dep Vixie-cron engine (OR-rule day semantics, bounded next-occurrence scan), an on-the-fly compiler with a lossless preset recognizer (accept only parse-set-equal recompiles), and a wall-clock-aligned minute ticker whose epoch-minute dedupe map makes double-fires impossible. `downtime-reconciliation`: heartbeat-bounded outage windows turn dead-process runs into "missed" and power-off schedules into "skipped" history that never launches and never counts.
- **Run handoff & lifecycle** — `pending-run-handoff`: single-use claim map carries cwd/runner/env from launch to whichever tab claims first, expiring unclaimed runs as missed. `launch-funnel`: five trigger kinds through one guarded tryLaunch — manual never counts, finished/disabled re-checked at fire time, agent runners headless with mid-run-delete result dropping. `osc-automation-exit`: exit codes recovered from the raw PTY stream over a private OSC channel emitted by the eval-hook. `store-migration-ladder`: versioned strict-schema file with repair-before-reject, sticky finished lifecycle, and webhook-id stability across edits. `secret-env-resolution`: parallel two-sided-skip resolver keeps unset secrets from clobbering env while values stay off the HTTP surface. `webhook-trigger-debounce`, `trigger-manager-wiring`: external POSTs coalesce through a stateless trailing debounce whose route always answers 202 on valid ids; all four managers share one `{debounceMs, isRunInFlight, getAutomation}` contract, re-sync after every store mutation, and funnel their single `due` emission into tryLaunch with their trigger kind.
- **Event & browser automation** — `git-watcher-daemon`: recursive fs.watch reconciled to the desired automation-cwd set, eager-seeded baselines plus empty-tree discovery so init+commit batches classify correctly; `burst-throttle`: leading-edge + trailing-flush coalescing that always classifies final state. `cdp-terminal-use`: PNG capture and mouse through the daemon's own CDP browser with render-landed equality oracle and mode-reporting fallbacks. `session-event-cwd-subtree`, `session-event-reconcile`, `watch-post-run-grace`, `watcher-signature-reconcile`, `watch-filter-null-passthrough`: the event/watch trigger plane — subdirectory-inclusive cwd matching, events+cwd signature rebuilds for armed listeners, recursive+cwd+filter signature rebuilds for fs.watch entries, a shared finish-armed post-run grace latch dropping side-effect events before they even debounce, and null-filename passthrough keeping nameless-event platforms firing under filters.
- **Agent runner & transcript plane** — `agent-run-status-event-stream`, `agent-tool-input-correlation`, `pi-binary-resolution-ladder`, `custom-harness-env-contract`, `rpc-jsonl-line-reader`, `agent-session-flatten`, `agent-changed-files-diff`, `agent-log-budget-ladder`: headless agent execution — spawn `pi --mode rpc` (or a user command) with a login-PATH-resolved binary minus secret shims, derive run status from the RPC event stream instead of process exit, correlate tool inputs by id under bounded eviction, carry prompts in env not argv for shell commands, read NDJSON with an LF-only splitter, flatten stored transcripts across both provider shapes with untilMs time travel, report impact as a symmetric git-status set diff, and store logs under marker-reserved caps with newest-keeping eviction. `agent-model-ttl-cache`: model enumeration behind a 5-min memo of pi's get_available_models RPC — shim-preferred spawn (secrets register providers), empty→--no-extensions retry, defensively mapped wire entries cached even when empty.
- **Git worktree plane** — `worktree-list-porcelain`: one `git worktree list --porcelain` read is the complete project view from any linked worktree, anchored on the realpath'd common dir so project name/repo-id never depend on caller cwd. `worktree-create-ladder`: fresh ref = origin/HEAD (one bounded fetch, else local HEAD), PR = pull/<N>/head pinned to a sha immediately, names are adjective-noun phrases retried only on "already exists". `stale-worktree-sweep`: sweepable iff auto-created ∧ old ∧ unoccupied ∧ clean, double-gated by git's own no---force refusal; emptied project folders reaped only when just the marker remains. `worktreeinclude-copy-contract`: gitignore-syntax allowlist delegated to git as pathspecs (`ls-files --others --ignored --exclude-standard`), copy failures can never fail a create git already succeeded. `worktree-delete-pty-guard`: one sessionsInPath predicate feeds the 409 active_pty guard, the sweep busy-check, and activeSessionCount in the list payload — attached AND parked shells block. `worktree-repo-config-store`: preferences keyed by sha256(mainRoot)[:12], fail-open zod reads, sanitize-on-write merge patches. `bounded-git-spawn-kernel`: SIGKILL-deadline, capture-capped, prompt-proof, never-rejecting runGit every call site shares.
