**Flow:** judge() splits the emitted action string on ';' → keeps pyautogui.click/moveTo/dragTo sub-actions → draws clamped markers on the BEFORE screenshot → caption text describing markers is generated by get_mouse_action_representation and mirrored in the narrator's system prompt so the model reads its own annotation grammar consistently.
**Invariant:** (1) Annotation depends on the string format the grounding actions emit — any change to emitter formatting (spacing in ", ") breaks coordinate parsing. (2) Drag lines require a MoveTo BEFORE the DragTo within one action; drag without prior moveTo draws from None (PIL raises). (3) Coordinates are clamped into bounds but NOT rescaled — judge images are same-resolution trajectory frames. (4) The representation builder asserts ≤2 mouse actions and exactly the moveTo→dragTo pair for drags.
