# Biome Foundation

## Use this for
Linters, formatters, or language-server tooling that must round-trip source losslessly and reason over small, flat, memoizable IRs. Also for hand-written recursive-descent parsers driven by an event stream with buffered lookahead, speculative parsing, and error recovery. Biome source and direct tests are ground truth; the capsules carry decisive excerpts and live graph retrieval.
