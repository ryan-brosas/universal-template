# Inclusive people language — is language person-first, respectful, and bias-aware?

**Source:** Mailchimp Content Style Guide §Writing About People, §Word List. **Question:** Are audiences, contacts, and identities described without biased, othering, or exclusionary terms?

## Person-first seam
**Path/Symbol:** copy about users, customers, employees, communities.
**Signature:** singular they; relevant-only age/disability; neutral gender; capitalize Black.
**Data Shape:** contacts/audiences are people (`they`), never “it”.

### Decisive pattern
```
Your contacts are people—use their preferred pronouns or their name if unknown.
```

**Flow:** write with person-first perspective internally and externally → refer to audiences and contacts with `they/them`, not `it` → don’t reference age or disability unless relevant; include specific age offset by commas when needed → avoid descriptors like young/old/elderly → avoid disability idioms (`lame`, `falling on deaf ears`) → for disability/medical mentions when relevant, ask person-first vs identity-first preference; never suffer/victim/handicapped (except “handicapped parking”) → don’t use guys/girls; prefer neutral roles (server not waitress) → singular `they` OK → LGBTQ+ terms as modifiers not nouns; avoid homosexual/lifestyle/preference → capitalize **Black**; lowercase **white** (Mailchimp race guidance) → use communicated pronouns or ask/use name → capitalize culture/ethnicity names; no hyphen in dual heritage (`Asian American`) → avoid new master/slave, blacklist/whitelist, and similar terms from word list.
**Invariant:** dehumanizing audience/contact language or banned terms in new copy fails inclusive language review.
**Probe:** grep word-list avoid terms; verify audience/contact pronouns; check form copy for irrelevant gender collection.

## Audience product terms seam
**Flow:** capitalize `lookalike` only as feature name “lookalike audiences” → don’t capitalize “audience” unless grammar requires.
**Invariant:** ambiguous “audience/it” phrasing fails person-first rule.
**Probe:** search `audience it` / `contacts it` patterns.

## Verdict
People-not-data language, singular they, inclusive identity terms, banned biased vocabulary. Learning note: `mailchimp-style-learning-note.md`.
