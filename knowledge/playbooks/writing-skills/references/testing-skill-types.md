# Select evaluation by skill type

The canonical evidence table is in `lift-evaluation.md`, under **Match proof to
the capability**. Use the cheapest evidence that addresses the proposed benefit.

Review reference and metadata changes directly against source and host discovery.
For routers, observe guidance being read and used during ordinary work, not a
prompted selection exercise. Procedures and load-bearing guardrails need
task-outcome evidence, not proof that the model repeats instructions. Existing
executable product helpers need their relevant tests. Use `testing-methodology.md`
only when a real failure warrants pressure testing.
